# TaSU-K25 (V4.4) README.md

## 概要
選択式テキストアドベンチャーゲームです。  
HTML, CSS, JavaScriptで構成されています。  
Text-adventure Simple Unit Kairi25の略称です。


## プロジェクト構成
```
TaSU-K25-main/
├── index.html  # 目次となるHTMLファイル
├── README.md/  # 本リードミーファイル
├── LICENSE     # ライセンス文書
├── source/     
│       ├── script.js   # 上層index.htmlの制御用
│       ├── style.css   # 上層index.html、全ストーリーのスタイルシート
│       └── (その他アイコン類)
│ 
├── stories/    # ストーリーをまとめています
│       └── Tochino     # ←このように、ストーリーごとに分けています
│               ├── index.html      # ストーリーのHTMLファイル
│               └── source/     # ストーリーのHTMLファイル
│                       ├── script.js   # ストーリーの制御に用いるJS
│                       └── (map/)	#ミニマップがある場合、このフォルダを作成しpng形式で画像を入れる
│                               ├── map(ベース地図番号).png
│                               ├── (レイヤー番号).png
│                               └── ...

└── md_generator/   # マークダウン形式ファイルからTaSU-K25のストーリーを作成
       ├── MDtoJSON # マークダウン→いったんJSONファイルへ
       ├── JSONtoTaSU   # JSONファイル→TaSU-K25のストーリーファイル作成
       └── JSONtoBTAP   # JSONファイル→BTAPのスクリプトへ(外部用)
```

## マークダウン形式でのストーリー作成について
所定の様式で、マークダウン形式でストーリーを作成できます。  
MDtoJSONでいったんJSON形式のコードに変換し、それをファイルにしてJSONtoTaSUで変換することで、ストーリーのHTMLやJSファイルのコードが生成されます。  

### 例
```
# ID
竹馬浬 2025.4; Story-Number=25_4.39.Cx.M1.栃

# FLAG
0

# ITEM
0. 鍵>>牛舎の鍵。
1. 円盾>>先祖が使っていたという、鹿の角がデザインされた古い盾。
2. ピッチフォーク>>長い柄と、その先端に広がった4本歯を持った農具

# MINIMAP_PREPARED

# MAP

## ～災いの日～
夏期
チャオ県 <ruby>太寧<rp>(</rp><rt>たいねい</rt><rp>)</rp></ruby>湾内 ロクボン島にて…
- 次へ>>nxp()
* 0
```

（以下省略）

### 構造について
大きく、４つにわかれています。

- ID
  - ただのストーリーの識別用ID。
- FLAG
  - ストーリーの分岐に用いるフラグの総数。（フラグ自体はv2.0時点で未実装）
- ITEM
  - ストーリーに登場するアイテム情報
- MAP
  - ストーリーの各描写文


### 書き方
見出し1(#)でID, FLAG, ITEM, MAPを書いて、その下に内容を入れます。  

また、ミニマップが準備してある場合、# MINIMAP_PREPAREDも記入してください。このストーリーでミニマップを利用しないなら、記入しないでください。  

#### ID
識別用記号を入れてください。

#### FLAG
フラグの数を示す数字を入れてください。

#### ITEM
0から始まるリストにアイテムを入れてください。
```
アイテム番号. アイテム名>>アイテム描写文
```

#### MAP
ページタイトル、描写文、選択肢、ミニマップの指定を入れてください。  
ページタイトルは見出し2(##)、選択肢は"-"ではじまる箇条書きリストの記法で代用しています。  
ミニマップの指定は"\*"ではじまる箇条書きリストの記法で代用しています。
また、ページにタグをつけたい場合は[]で囲ってください。ページ間ジャンプに有用です。

```
## ページタイトル([タグ])
描写文1行目
描写文2行目
. . .

- 選択肢名>>コマンド
* （レイヤー番号）m（ベース地図番号）
```

### 描写文の特殊な制御について
** この項目は現在稼働テスト中 **  
空白行を入れたい場合、その行に「makespace」と入れてください。


### 選択肢のコマンドについて
| コマンド名 | 意味 | コメント |
| - | - | - |
| nxp() | 次のページへ | next pageの意 |
| bcp() | 前のページへ | back pageの意 |
| mov(数字) | 数字番目のページに飛ぶ | moveの意。実際にはtobコマンドをよく使うことと思う。ページ番号は0から始まる。 |
| tob(タグ名) | タグのついているページに飛ぶ | 飛ぶの意 |
| ifhave(アイテム番号) | その番号のアイテムを持っていればtrueを、さもなくばfalseを返す。 | if文の条件分岐と合わせて使う。例：if(ifhave(1)){ /*持っていた場合*/ }{ /*持っていない場合*/ } |
| getitem(アイテム番号) | その番号のアイテムを得る。 |  |
| restart() | リセットして、最初から始める |  |


### ミニマップの指定について
ミニマップは、文字情報だけではわかりづらい、地理的な位置情報を、ユーザーが視覚的にわかりやすくなることを目的とした機能です。必要であれば利用してください。  

ベースとなる地図画像の上に、現在地ごとに用意されたレイヤー画像を上から重ねることで、現在地を表現します。  

- 先述の通り、ミニマップが準備してある場合、# MINIMAP_PREPAREDを事前に記入してください。  
- ミニマップ画像はpng形式とし、各ストーリーフォルダのsource/map/下に置いてください。  
- そのファイル名は、
  - ベース地図については** map(ベース地図番号).png **
  - レイヤーについては** (レイヤー番号).png **
- としてください。
- どちらの番号も、1以上の自然数とします。  

```
ベース地図番号の例：
map1.png
map2.png

レイヤー番号の例：
1.png
2.png
``` 

また、ストーリーの各ページごとにどのベース地図とレイヤーを設定するかを、以下の構文で設定してください。  
```
* （レイヤー番号）m（ベース地図番号）
```

- ベース地図番号が1のとき、m以下の文章は省略可能とします。
- レイヤーを表示しない場合は、かわりに0としてください。

```
ベース1の上に、レイヤー3を重ねる場合：
* 3m1
もしくは
* 3


ベース2の上に、レイヤー4を重ねる場合：
* 4m2

ベース1だけ表示してレイヤーは表示しない場合：
* 0m1
もしくは
* 0
```
